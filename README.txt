DV TRANSPORTE — PREMIUM REDESIGN

STARTEN
ZIP vollständig entpacken. index.html im Browser öffnen.
Alle Bilder, Schriften, CSS und JavaScript liegen lokal im Ordner assets.
Kein npm, Build-Schritt oder Framework notwendig.

ENTHALTEN
Startseite, Leistungen, Unternehmen, Kontakt, Impressum, Datenschutz und 404.
Interaktive Leistungswahl, Galerie mit Großansicht und Tastaturbedienung,
mobiles Menü, dezente Scroll-Einblendungen und Lesefortschrittsanzeige.
Reduzierte Bewegung wird respektiert. Inhalte bleiben ohne JavaScript lesbar.

WEBSpace
Für die Domain dvtransporte.de den Inhalt dieses Ordners ins Webroot laden.
PHP 7.4 oder neuer und konfiguriertes PHP mail() sind für den Formularversand
notwendig. Der Erfolgshinweis bestätigt nur die Übergabe an den Mailserver.
Bitte eine echte Testanfrage auf dem Zielhosting prüfen.
Bei einer anderen Domain Canonical/OG-URLs, strukturierte Daten, sitemap.xml,
robots.txt und Mailabsender anpassen. .htaccess setzt Apache voraus.

ANPASSEN
Farben: assets/css/main.css, Variablen am Anfang.
Inhalte: direkt in den jeweiligen HTML-Dateien.
Interaktionen: assets/js/main.js.
Formular-Empfänger und Absender: send.php.

DATENGRUNDLAGE UND PRÜFUNG
Bilder, Firmenangaben, 10-LKW-Angabe und Rechtstexte stammen aus der gelieferten
Vorlage. Rechtstexte wurden übernommen, nicht rechtlich geprüft.
Lokale Pfade, Ankerziele, JSON-LD, CSS und JavaScript wurden technisch geprüft.
Ein vollständiger visueller Browsercheck war durch die Zugriffsbeschränkung
der Arbeitsumgebung nicht möglich. PHP-Mailversand ist hier nicht getestet.
Vor Veröffentlichung bitte im Desktop- und Smartphone-Browser ansehen.

DESIGN-RECHERCHE
Siehe DESIGN-RECHERCHE.md für Quellen und Gestaltungsentscheidungen.
Schrift: Barlow / Barlow Condensed, lokal eingebunden, SIL Open Font License
in assets/fonts/OFL.txt. Originalbilder unverändert aus der gelieferten ZIP.
